# Support

OpenVINO-Nim-API is an early, community-maintained project. It is not an
Intel-supported product and it does not provide a service-level agreement.

Before opening an issue:

1. Check [Getting started](docs/getting-started.md) and
   [Troubleshooting](docs/troubleshooting.md).
2. Confirm the runtime, Nim version, operating system and device are in the
   [compatibility matrix](docs/compatibility.md).
3. Reproduce the problem with the smallest example possible, ideally the
   included ReLU fixture.

Open a [GitHub issue](https://github.com/AbyssGG/OpenVINO-Nim-API/issues/new/choose)
for reproducible bugs and feature proposals. Please include command output,
the exact error, and whether the failure occurs in the managed or raw layer.
Do not include credentials, private model files or runtime binaries.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md) instead of
opening a public issue.
